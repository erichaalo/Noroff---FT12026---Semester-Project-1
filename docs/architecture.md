# Site architecture
## Sitemap
index.html → Home
explore.html → Explore
exhibitions.html → Exhibitions
events.html → Events
visit.html → Visit (about + contact)
get-involved.html → Get Involved
## Navigation
- Header: logo → Home; nav in the order above; hamburger below 768px
- Footer: same six links, plus address, hours summary, email
- Cross-links: Home → Explore/Events/Visit; Explore → all; every "contact us" → visit.html#contact
## User journeys
1. Kid, 10, on a phone: Home hero → Explore → Exhibitions (Rob the Robot) → shows parent → Visit for hours
2. Parent planning a weekend: Home → Events (Night in the Museum) → Visit for hours and admission → mailto form to book
3. Teacher: Home → Get Involved → mailto form to arrange a class visit
