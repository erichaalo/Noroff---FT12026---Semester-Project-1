# docs/scope.md
## Goal
Responsive multi-page site for the Community Science Museum, aimed at
children 7–15 and families, that inspires an in-person visit.
## Theme / concept
A colorful but not childish website to create hype and buzz using large images to quickly convey what the site is about.
## Pages 
Home, Explore, Exhibitions, Events, Visit, Get Involved
## Deliverables
- Live site · Figma prototype (desktop + mobile) · style guide
- GitHub Project board with roadmap view · public repo
- Reflection PDF: Erik_Hamre_SP1_Mar26FT.pdf
## Success criteria (grading)
- Style guide and prototype: professional standard
- Planning: meticulous, roadmap view
- HTML: wide semantic range, valid, no accessibility errors
- CSS: wide feature range, highly responsive, design-accurate
## Resources
- Assets: CommunityScienceMuseum copy doc, image pack from Noroff
- Tools: VS Code, Figma, Squoosh, W3C validator, WAVE, GitHub Pages
- Reuse: nav, CSS variables and header from the Rainy Days assignment
## Out of scope
JavaScript, frameworks, real forms/login 
## Constraints
Solo, 15 days, deadline Mon 21 Sep
